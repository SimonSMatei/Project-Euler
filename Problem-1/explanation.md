# Problem 1
If we list all the natural numbers below 10 that are multiples of 3 or 5, we get 3, 5, 6 and 9. The sum of these multiples is 23. Find the sum of all the multiples of 3 or 5 below 1000.

# Solution Explained
This problem is very simple and can be done easily in Python. Traditionally, a loop would be used to find the multiples of 3 or 5 and then add them to a total. However, with Python, it is possible to do all of this with one line of code. Python has the capability to use a list comprehension (an inline for loop) to populate a list, and then the sum() function can be used to get the total. All of these steps can be done in one line. The solution is simple and efficient.
